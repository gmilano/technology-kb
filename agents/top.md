## Nota de método: dos límites reales de la API

1. **`search/repositories` da falsos negativos por repo, no por organización.** `All-Hands-AI/OpenHands`,
   `block/goose` y `sst/opencode` devuelven HTTP 422 con `repo:<slug>`, mientras repos hermanos
   de la *misma* organización (`All-Hands-AI/openhands-resolver`, `block/goose2`,
   `block/goose-plugins`) se devuelven normalmente. Los tres están **vivos** por `ls-remote`.
   Sexta confirmación de este patrón en esta familia de KBs.
2. **`gh api repos/<slug>` responde 403** para cualquier repo no adjuntado a la sesión. No es
   una alternativa. **La existencia se decide con `ls-remote`, punto.**
